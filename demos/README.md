# Real-file demonstrations

[The Last Lighthouse](last-lighthouse/README.md) is a complete chamber-musical scene with original MP4 projections, MP3/WAV score, spoken crew guide, click, synchronous effects, asynchronous ambience and one-shots, lighting MIDI, grouped holds, automation and a portable package. It includes independent MIDI logging, an eight-channel line check, an async pause/seek check, and repeatable OBS/BlackHole validation tools.
